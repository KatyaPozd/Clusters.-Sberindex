# Динамическая атрибутированная экономическая сеть МО СЗФО

Воспроизводимый пайплайн анализа экономической структуры 282 муниципальных
образований Северо-Западного федерального округа за 2024 год.

## Запуск проекта

### 1. Установка зависимостей
pip install -r requirements.txt

### 2. Подготовка данных
Исходные данные уже помещены в папку data/, два файла:
- data.csv - помесячные траты МО (17 170 строк).
- szfo_boundaries.gpkg - геометрии 393 МО СЗФО.

### 3. Настройка параметров
Все гиперпараметры вынесены в config.yaml. При необходимости отредактируйте:
- algorithm.knn_k - число ближайших соседей в KNN-графе (по умолчанию 10).
- algorithm.leiden_resolution - параметр resolution Leiden (по умолчанию 1.0).
- algorithm.leiden_seed - seed для воспроизводимости (по умолчанию 42).
- features.categories - список категорий трат.
- features.seasons - разбиение месяцев по сезонам.

### 4. Запуск анализа
Откройте notebook.ipynb в Jupyter/Colab и выполните все ячейки сверху вниз.
Результаты сохранятся в outputs/figures/ и outputs/tables/.

## Что делает пайплайн

1. Собирает признаки МО: 5 долей трат + mobility + salary_rub.
2. Строит PCA (3 компоненты).
3. Строит KNN-граф экономической близости (K = 10).
4. Кластеризует Leiden по 4 сезонам 2024 года.
5. Сопоставляет кластеры между сезонами (венгерский алгоритм).
6. Визуализирует: карты по сезонам, timeline, Sankey, PCA-триптих.

## Воспроизводимость

Все результаты детерминированы: фиксированы seed=42 для Leiden
и random_state=42 для PCA. При повторном запуске получите те же числа.
